# moyu-desktop

跨平台（macOS / Windows）的**置顶播放器 + 快速弹幕**，外观伪装成推广弹窗。

只负责窗口、热键和托盘；播放与发送由内置的 `moyu` 守护进程（`127.0.0.1:8731`）提供——
打包版会把守护进程一起塞进 `resources/moyu`，启动时用 Electron 自带的 Node 拉起来，
**不需要另外装 Node**。

## 启动

```bash
./run.sh          # 或 npm start（前提：环境里没有 ELECTRON_RUN_AS_NODE）
```

首次使用需要导入登录态：托盘图标右键 → **导入登录态（从 Chrome）**。

## 热键

| 热键 | 作用 |
|---|---|
| `⌘D` / `Ctrl+D` | 发弹幕输入框（黑听时也能用，不会把画面拉出来） |
| `⌘⇧D` / `Ctrl+Shift+D` | 黑听 / 显示画面 |
| `⌘⇧[` / `⌘⇧]` | 不透明度 ±10% |
| `⌘⇧T` | 切换「始终置顶」 |
| `⌘⇧A` | 侧栏广告开关（竖屏直播时填满两侧黑边） |
| `⌘⇧1` `⌘⇧2` | 切换广告皮肤：促销秒杀 / 拜耳除蟑 |

## 外观

- 两套广告皮肤，随时切换：
  - **促销秒杀**：橙色描边 + 「限时秒杀 · 距结束 … · 立即抢购」
  - **拜耳除蟑**：绿色描边 + 「拜耳 · 专业除蟑 · 一窝端」
- 顶栏右侧藏着真功能：透明 ±、置顶、🎧 黑听、🔇 声音、`×` 退出
- 中间画面 **鼠标穿透**，只有顶栏和底部输入栏接收点击
- 竖屏直播时，两侧黑边可以填成动态广告

## 打包

```bash
npm run dist:win    # → dist/moyu-live-<version>-win.zip
npm run dist:mac
```

## 说明

- 窗口无边框，顶栏即拖拽区
- 位置 / 大小 / 不透明度 / 置顶状态 / 侧栏广告开关都记在本地
- Windows 上同一份代码即可运行
