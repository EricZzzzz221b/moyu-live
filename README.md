## 这是什么

一个把 B 站直播塞进工作流的工具，三个层次随便挑：

| 形态 | 说明 |
|---|---|
| **网页播放器** | 本地起一个服务，浏览器打开就能看，带弹幕输入、FLV 低延迟 |
| **桌面浮窗** | Electron 小窗，**永远置顶在所有应用之上**，还能调透明度、一键黑听 |
| **DSH 插件** | 在 DeepSeek Harness 里内嵌小窗，`/zhibo` 起直播、`/dm` 发弹幕 |

三个共用同一个本地守护进程，登录态、播放地址、弹幕通道都只有一份。

## 它解决什么

- 直播间在后台播放，但**发弹幕还得切回网页** → 现在 `⌘D` 随手发
- 画面被窗口挡着、切来切去找不到 → 桌面浮窗恒置顶，鼠标穿透
- 一直盯着视频太显眼 → 伪装成推广弹窗 + 一键黑听（只留声音）
- 延迟比网页慢好几秒 → 换成 FLV 直连转发，1 秒级

## 快速开始

### 1. 拿登录态（发弹幕必需）

```bash
cd moyu
node bin/auth.mjs
```

会从本机 Chrome 里读出 bilibili 的 cookie，写到 `moyu/.cookie.json`（权限 600，不上传、不打印）。

> macOS 上如果报 `EPERM`，去「系统设置 → 隐私与安全性 → 完全磁盘访问权限」把终端加进去，重开终端再跑。

### 2. 起服务

```bash
node bin/moyu.mjs play 161574          # 房间号或直播间链接都行
node bin/moyu.mjs play --no-open       # 用上次的房间，不自动开浏览器
```

浏览器打开 `http://127.0.0.1:8731/` 就能看。也可以只起服务、用桌面浮窗看：

```bash
cd ../moyu-desktop
./run.sh          # macOS / Linux
npm start         # 前提：环境里没有 ELECTRON_RUN_AS_NODE
```

Windows 直接下载 [Releases](../../releases) 里的 `moyu-live-*-win.zip`，解压双击 `moyu-live.exe`。

### 3.（可选）装进 DSH

把 `moyu-dsh/` 目录用 DSH 的插件管理器安装，然后：

```
/zhibo 161574        # 起直播 / 换台，房间号或整条链接都行
/dm 这波操作可以      # 在当前输入框里直接发弹幕，不进对话
```

## 热键

| 热键 | 作用 |
|---|---|
| `⌘D` / `Ctrl+D` | 弹出发弹幕输入框（**黑听时也能用，不会把画面拉出来**） |
| `⌘⇧D` / `Ctrl+Shift+D` | 黑听 / 显示画面 |
| `⌘⇧[` / `⌘⇧]` | 调不透明度 |
| `⌘⇧T` | 切换始终置顶 |
| `⌘⇧A` | 侧栏广告开关（竖屏直播时填满两侧黑边） |
| 双击 `Esc` | 收起 DSH 面板 |

## 工作原理

```
┌──────────────┐   HTTP/SSE   ┌──────────────────────────┐
│ 网页播放器     │ ◄──────────► │  moyu 守护进程 (8731)      │
│ 桌面浮窗       │              │  · 登录态                 │
│ DSH 插件      │              │  · 播放地址（FLV / HLS）    │
└──────────────┘              │  · 弹幕收发 + 回执          │
                              │  · FLV 本地转发            │
                              └──────────────────────────┘
```

几个踩过的坑，都写在代码注释里了：

- **FLV 不能直连**：CDN 看到浏览器带的 `Origin` 会返回 403，所以由本地服务带 `Referer` 转发
- **弹幕 WS 的 uid 必须是 0**：传真实 uid 又不带 cookie，服务端会静默不回任何包
- **发送成功 ≠ 真的发出去了**：房间有发言限制时会"吞弹幕"，`code:0` 也不代表可见
- **昵称会被打码**（`埃***`），所以认人一律用 uid
- **`getDanmuInfo` 会 -352 风控**，收弹幕走老端点 `room/v1/Danmu/getConf`

## 常见问题

**画面比网页慢？**
先看画面左下角角标：显示 `FLV` 且缓冲 < 0.5s 就已经到底了——剩下的是 B 站编码端的 GOP（约 2 秒），没有更低的公开通道。

**发出去没反应？**
可能被吞了。房间的发言限制、账号风控都会让接口返回成功但消息不显示。

**DSH 面板白屏 / 显示"守护进程没在跑"？**
守护进程挂了，重跑第 2 步，或在 DSH 里 `/zhibo` 会自动拉起。

**Windows 上能装 DSH 插件吗？**
`moyu/` 和 `moyu-desktop/` 是跨平台的；`moyu-dsh/` 依赖 DSH 本身。
